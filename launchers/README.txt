AMPHICOS 3D PLATFORM - OFFLINE EDITION
======================================

Runs without internet and without installation. Copy this whole folder (USB drive, disk or laptop) and keep the files together.

START
  Windows : double-click  "Start Amphicos (Windows).bat"
  macOS   : double-click  "Start Amphicos (Mac).command"
            (first time only: right-click it, choose Open, then Open again)
  Any OS  : you can also double-click  index.html  (Chrome or Edge recommended)

Full screen: F11 (Windows) or Ctrl+Cmd+F (Mac). Esc steps back.

BEST RESULTS
  - Google Chrome or Microsoft Edge, current version; hardware acceleration ON
    (browser Settings > System > "Use graphics acceleration when available").
  - Laptop plugged in; Windows power mode "Best performance".
  - Laptops with two graphics chips (Windows): Settings > Display > Graphics > set the browser to "High performance".
  - On a large 4K TV, Exhibition mode keeps the 3D smooth automatically (View menu > Quality).
  - Samsung TVs: Game Mode on, Auto Motion Plus off, Input Signal Plus on, Picture Size "Fit to screen".
  - Frame-rate check: open the View menu and switch on the frame counter; a steady 50-60 fps is ideal.
